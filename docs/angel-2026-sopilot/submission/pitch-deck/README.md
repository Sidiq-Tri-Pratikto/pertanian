# Pitch Deck SOPilot (12 slide)

Deck dibuat dengan tipe Slides di claude.ai: https://claude.ai/artifact/8C1cci3snh22TQMkH3ZKWH (privat sampai dibagikan).

**Untuk submit, unduh PDF atau PPTX dari halaman deck** (menu Share/Export). Berkas di folder ini hanya cadangan sumbernya:

- [deck.json](deck.json): indeks (judul, urutan slide, bagian, font).
- [slides/](slides/): satu berkas HTML per slide, dalam format slide Slides (kanvas 1920×1080, gaya inline). Bukan HTML mandiri, jadi tidak tampil rapi bila dibuka langsung di browser.
- [images/](images/): tiga tangkapan layar prototipe untuk slide 7. Di `slides/prototipe.html` gambar dirujuk lewat `/_blob/<id>` yang hanya berlaku di artifact online; untuk membangun ulang, unggah ulang gambar ini dan ganti id-nya.

Urutan: cover · masalah · terdampak · solusi · alur · arsitektur · prototipe · pembeda · rencana · hilirisasi · tim · penutup.
