Tujuh komponen. Parser memecah SOP jadi kalimat bernomor. Extractor (LLM) mengisi JSON perantara beserta jejak ke kalimat sumber. Checker menemukan ambiguitas dan menyusun pertanyaan; jawaban admin atau pemilik SOP diubah Patcher menjadi perubahan JSON. Generator deterministik membangkitkan BPMN executable dan memvalidasinya dengan bpmnlint; Simulator menjalankannya; Simplifier menyusun poster. Prinsip kunci: LLM tidak pernah menulis XML.
