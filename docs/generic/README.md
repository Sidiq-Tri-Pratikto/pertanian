# Spesifikasi produk

| Produk | Cakupan | Dokumen |

| HematDaya | Pemantauan listrik dan saran berbasis bukti untuk rumah tangga, usaha dan industri; modular monolith dengan reuse terpelihara | [Paket dan urutan penggunaan](hematdaya/README.md) · [PRD ID](hematdaya/01_PRD_HematDaya_Generic_ID.md) · [PRD EN](hematdaya/01_PRD_HematDaya_Generic_EN.md) · [Design system EN](hematdaya/04_Claude_Design_System_HematDaya_EN.md) · [Prompt sistem EN](hematdaya/05_Prompt_Claude_Design_System_EN.md) · [Handoff aplikasi EN](hematdaya/02_Claude_Design_HematDaya_EN.md) · [Prompt aplikasi EN](hematdaya/03_Prompt_Claude_Design_EN.md) |

Setiap PRD menetapkan perilaku, batas cakupan serta bukti yang diperlukan untuk penerimaan produk. Persetujuan arah produk/arsitektur, keberadaan spesifikasi dan hasil implementasi/verifikasi harus dilaporkan terpisah. Urutan HematDaya adalah design system terlebih dahulu, kemudian prototipe aplikasi yang memakai sistem tersebut. Handoff aplikasi tetap memuat salinan PRD lengkap; identitas/versi sistem yang benar-benar diimpor atau dipilih dicatat terpisah.
