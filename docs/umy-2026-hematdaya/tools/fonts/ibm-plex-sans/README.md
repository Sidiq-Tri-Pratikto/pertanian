# IBM Plex Sans for the UMY proposal template

These unmodified TrueType fonts reproduce the label typeface used in the revised
UMY Hackathon DeepTech 2026 handbook's proposal forms. Proposal body text uses
separately installed, licensed Times New Roman; no Microsoft font is redistributed.

- Upstream: [IBM/plex](https://github.com/IBM/plex).
- Pinned commit: `71f558992315a12ca1f06a2215d57962a1992162`.
- Source directory: `packages/plex-sans/fonts/complete/ttf/`.
- Retrieved: 24 October 2026.
- Faces: Regular, Bold, SemiBold, Italic, and BoldItalic.
- License: SIL Open Font License 1.1, included verbatim in `license.txt`.

The renderer registers these files as the `Plex` family and `Plex-SemiBold`.
