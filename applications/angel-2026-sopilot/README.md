Prototipe interaktif dengan **data contoh** (SOP Pengadaan Barang/Jasa fiktif). Belum ada mesin ekstraksi LLM, generator BPMN, atau simulator sungguhan; ini untuk memvalidasi alur dan pengalaman pengguna (TKT 2–3).
