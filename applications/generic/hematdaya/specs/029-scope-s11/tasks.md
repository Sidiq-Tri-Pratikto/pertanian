## Contract decisions

- The 028 selection GET describes current site time. The preview calculates selected members only and returns candidates whose stored bindings intersect that period. Use bounded separate previews for comparison values and candidate discovery. The service aggregate supplies the child-group value.
- The PUT compares the preview’s revisions and local dates/timezone against the original period request. A changed cutoff or measurement revision within that local period triggers server re-evaluation without making the preview stale by itself.
- 028 has no operation ID or write-status endpoint. A same-pair read cannot settle a pending PUT. A fresh preview and separately authorized compare-and-set write are safe because at most one request using that base can advance the revision pair. Preserve older uncertainty until a higher pair is durably fenced.
- The owner/site pair is independent of the combined data revision. Compare binding before selection. An external observation can fence old data in memory even if durable storage fails completely. A cold offline launch only has the successfully persisted evidence.
