# Feature specification — Compact MVP layout

**Status**: Implemented and verified locally
**Depends on**: 013, 014, 015, 022, 027, 029, 047
**Covers**: UX-02, UX-08, UX-17, UX-18, UX-19, UX-20, AT-45, AT-55, AT-56, AT-57, AT-58, S03, S04, S07, S10, S11

## US1 — Scan essentials on phones and wide screens

- FR-001. Use 24 logical pixels between sections and 8–16 within groups. Use one column below 768 and a supporting column on populated Home, Devices and Insights above that breakpoint.
- FR-002. Keep period, scope, kWh, and qualifiers together. Supporting content follows the main reading order and has no duplicated data.
- FR-003. Mirror the hierarchy and widths in the standalone prototype.

## US2 — Complete a task at any supported size

- FR-004. Keep scope and CSV forms single-column with reachable actions, focus and keyboard behavior.
- FR-005. Preserve data alternatives, status semantics, and 48-unit targets. Reflow at 320, 390, 768 and 1280 px and preserve content at 200% text.
