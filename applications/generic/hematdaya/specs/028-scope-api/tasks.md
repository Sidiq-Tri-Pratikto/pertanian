## Contract decisions to carry into implementation

- Use `0` for the absent selection concurrency token and a positive revision for a saved selection. Legacy sites use all active assets. Archive keeps a stored ID, restore makes it eligible again, and reset clears it under the binding fence. An unchanged saved selection round-trips even with archived members.
- Site summary exposes nullable `selection_revision` and `binding_revision` without changing the combined data revision. 029 uses both tokens, the exact included IDs, the resolved window and the 034 owner and scope epoch. Preview responses stay outside the successful-summary cache.
- PUT repeats the original period request and the preview's resolved timezone and local dates. A changed period or revision returns `SCOPE_STALE`. A moving cutoff within the same period triggers re-evaluation with one captured site time.
