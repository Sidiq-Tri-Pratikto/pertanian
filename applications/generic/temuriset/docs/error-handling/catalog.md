# Error Catalog

One row per error. Keep in sync with `app/core/errors/codes.py` and `public.py`. Consumers branch on the public code, never on message text. User messages are Indonesian; everything else stays English.

| Internal code | Public code | HTTP | Default message | Trigger | retryable | retry_after_seconds | max_attempts |
|---|---|---|---|---|---|---|---|
| `APP-UNKNOWN` | `INTERNAL_ERROR` | 500 | Permintaan belum dapat diselesaikan. Hubungi dukungan dan sebutkan ID referensi yang ditampilkan. | Any unrecognized failure | false | - | - |
| `APP-REQUEST-INVALID` | `BAD_REQUEST` | 400 | Permintaan belum dapat diproses. Periksa isian Anda lalu coba lagi. | Request violates a business rule | false | - | - |
| `APP-NOT-FOUND` | `NOT_FOUND` | 404 | Data yang diminta tidak ditemukan. Periksa alamatnya lalu coba lagi. | Resource does not exist | false | - | - |
| `APP-CONFLICT` | `CONFLICT` | 409 | Permintaan bertentangan dengan kondisi saat ini. Tinjau datanya lalu coba lagi. | State conflict | false | - | - |
| `APP-DB-ERROR` | `DATA_ERROR` | 500 | Permintaan gagal karena kesalahan data. Hubungi dukungan dan sebutkan ID referensi. | Database failure | false | - | - |
| `APP-DB-UNAVAILABLE` | `DATABASE_UNAVAILABLE` | 503 | Layanan data sedang tidak tersedia. Coba lagi beberapa menit lagi. | Connection, pool, or operational failure | true | 30 | 3 |
| `APP-CAPABILITY-UNAVAILABLE` | `CAPABILITY_UNAVAILABLE` | 403 | Fitur ini tidak tersedia pada layanan ini. Hubungi pengelola layanan bila Anda memerlukannya. | Route guarded by `require_capability` for a capability this deployment does not select | false | - | - |
| `APP-UNAUTHENTICATED` | `UNAUTHENTICATED` | 401 | Anda perlu masuk terlebih dahulu. Masuk lalu coba lagi. | No trusted acting party (until 007: the development-only `X-Party-Id` header is missing, or the service is not in development) | false | - | - |

| `APP-IDEMPOTENCY-CONFLICT` | `IDEMPOTENCY_CONFLICT` | 409 | Kunci permintaan ini sudah dipakai untuk isi berbeda. Gunakan kunci baru untuk permintaan baru. | `Idempotency-Key` reused by the same actor and operation with a different path or body | false | - | - |
| `APP-FORBIDDEN` | `FORBIDDEN` | 403 | Anda tidak memiliki akses untuk permintaan ini. Hubungi pemilik data bila perlu akses. | A cookie-bearing unsafe request from another origin; from 007, a visible resource without the capability | false | - | - |

| `APP-CODE-EXPIRED` | `CODE_EXPIRED` | 422 | Kode verifikasi sudah tidak berlaku. Minta kode baru lalu masukkan kode tersebut. | No open code, older than 10 minutes, or five wrong guesses | false | - | - |
| `APP-RATE-LIMITED` | `RATE_LIMITED` | 429 | Terlalu banyak permintaan kode. Tunggu sebentar lalu coba lagi. | Over 5 code requests per email or 20 per address in an hour, or over five new pitches per actor in 24 hours (policy `pitch-rate-limit` v1, its own message); `retry_after_seconds` says when the window frees up | true | per request | 3 |
| `APP-STALE-CONTEXT` | `STALE_CONTEXT` | 409 | Anda kini bertindak sebagai pihak lain di tab berbeda. Muat ulang halaman lalu ulangi tindakan Anda. | `acting_party_id` differs from the session's active party | false | - | - |
| `APP-INVITATION-EXPIRED` | `INVITATION_EXPIRED` | 410 | Undangan ini sudah tidak berlaku. Minta undangan baru kepada pengelola organisasi. | Invitation older than seven days, revoked, or already accepted | false | - | - |
| `APP-PUBLICATION-INVALID` | `VALIDATION_FAILED` | 422 | Draf belum siap diterbitkan. Lengkapi isian yang ditandai lalu terbitkan lagi. | Publishing a draft that breaks a PRD publication rule; `details` names each field in Indonesian | false | - | - |
| `APP-FILE-TOO-LARGE` | `FILE_TOO_LARGE` | 422 | Berkas melebihi batas 20 MB untuk PDF dan DOCX (5 MB untuk gambar). Kecilkan berkas lalu unggah lagi. | Declared size over the limit before upload, or more bytes than declared during it | false | - | - |
| `APP-FILE-TYPE-UNSUPPORTED` | `FILE_TYPE_UNSUPPORTED` | 422 | Jenis berkas ini tidak didukung. Unggah PDF, DOCX, PNG, JPEG atau WEBP. | Declared media type not accepted | false | - | - |
| `APP-FILE-NOT-AVAILABLE` | `FILE_NOT_AVAILABLE` | 409 | Berkas ini belum tersedia atau ditolak saat pemeriksaan. Tunggu pemeriksaan selesai. | Download of a quarantined or rejected version | false | - | - |

| `APP-FIELDS-INVALID` | `VALIDATION_FAILED` | 422 | Ada isian yang belum valid. Perbaiki isian yang ditandai lalu simpan lagi. | A save whose fields break a rule, such as a budget with a negative minimum; `details` names each field in Indonesian and nothing is stored | false | - | - |
| `APP-INVALID-TRANSITION` | `INVALID_TRANSITION` | 409 | Status ini tidak dapat diubah dengan cara itu. Muat ulang untuk melihat status terbaru. | A status change the current status does not allow, such as reactivating a closed support request | false | - | - |
| `APP-DUPLICATE-PITCH` | `DUPLICATE_PITCH` | 409 | Pitching untuk kebutuhan dan mandat ini sudah ada. Buka pitching yang ada untuk melanjutkannya. | An active pitch exists for the same source, recipient, opportunity and purpose; the envelope adds `pitch_id` | false | - | - |
| `APP-TARGET-CLOSED` | `TARGET_CLOSED` | 409 | Mandat ini tidak lagi menerima pitching baru. Diskusi yang sudah berjalan tetap berlanjut. | Submitting to an opportunity that is not active or whose route no longer accepts pitches; the envelope adds `reason` | false | - | - |
| `APP-PREFLIGHT-STALE` | `PREFLIGHT_STALE` | 409 | Ada yang berubah sejak pemeriksaan. Periksa ulang sebelum mengirim; brief Anda tetap tersimpan. | Unknown or expired preflight token, or a pinned version, permission or configuration changed; the envelope adds `reason` | false | - | - |
| `APP-NOT-READY` | `NOT_READY` | 422 | Masih ada syarat pengajuan yang belum selesai. Lengkapi syarat yang disebutkan lalu periksa ulang. | Readiness is not `READY_TO_SUBMIT`, or a required file was not chosen; the envelope adds `requirement` | false | - | - |
| `APP-REQUIRED-ANSWERS-MISSING` | `REQUIRED_ANSWERS_MISSING` | 422 | Masih ada pertanyaan wajib yang belum dijawab. | `APP-LISTING-SUSPENDED` | `LISTING_SUSPENDED` | 409 | Daftar ini sedang ditangguhkan. Hubungi pengelola layanan bila Anda merasa ini keliru. | Saving, publishing, activating or referencing a listing an operator suspended | false | - | - |
| `APP-BOOKING-CONFLICT` | `BOOKING_CONFLICT` | 409 | Waktu ini bentrok dengan jadwal peserta. | `APP-PROPOSAL-CLOSED` | `PROPOSAL_CLOSED` | 409 | Usulan waktu ini sudah tidak terbuka. Muat ulang untuk melihat usulan terbaru. | Accepting or cancelling a proposal that expired, was superseded, accepted or cancelled; the envelope adds `reason` | false | - | - |
| `APP-ENTITY-REQUIRED` | `ENTITY_REQUIRED` | 422 | Kerja Sama ekuitas memerlukan badan usaha yang sudah berdiri. Pilih jenis lain atau dirikan badan usaha dulu. | Proposing an EQUITY relationship for a pitch whose source has no identified legal entity (AC21); discussion stays open | false | - | - |
| `APP-MEETING-NOT-COMPLETED` | `MEETING_NOT_COMPLETED` | 409 | Ringkasan Kerja Sama diusulkan setelah pertemuan selesai. Catat hasil pertemuan bersama pihak lain dulu. | Proposing a relationship before both parties recorded a meeting as completed | false | - | - |

A missing `Idempotency-Key` on a consequential POST is `BAD_REQUEST` with `details` naming the header.

Framework failures use the status map in `public.py`: `UNAUTHORIZED` 401, `FORBIDDEN` 403, `METHOD_NOT_ALLOWED` 405, `VALIDATION_FAILED` 422, `RATE_LIMITED` 429.
